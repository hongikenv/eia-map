국립생물자원관·물환경정보시스템 등에서 받은 지도파일을 data 폴더에 넣어 쓰는 방식
조사지역 · 유역

GitHub 저장소에 data 폴더를 만들고 GeoJSON 파일을 올리면 체크만으로 켜집니다. 파일 이름: winter_census.geojson(겨울철 조류 동시센서스 조사지역), tmdl_unit_basin.geojson(수질오염총량 단위유역). SHP는 QGIS 등에서 GeoJSON으로 저장해 올리세요. 좌표계가 TM이면 자동으로 바꿔 줍니다. 파일을 올리기 전에는 오른쪽 레이어 창의 '＋ 파일'로 직접 올려 써도 됩니다.

지도를 옮기면 그 범위도 이어서 받아옵니다. 브이월드 주제도는 시군구가 보일 정도(1:10만 안팎), 생태자연도는 읍면동이 보일 정도로 확대해야 받아옵니다.
